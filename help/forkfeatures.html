Engauge Digitizer - New Features in This Fork

This fork of Engauge Digitizer adds opt-in features on top of the upstream application. Every one of them is off by default, so a fresh installation behaves exactly like the upstream release until each feature is turned on in the settings. The added menu entries are listed here together with the setting that enables them.

Auto Curve Detection

The Digitize > Auto Curve Detection Tool digitizes a whole curve from a single click. Click any piece of the curve and points are placed along every connected piece of it, which removes the tedious work of filling each scan gap by hand. Two gates keep the chain on the curve and can be tuned in Settings > Segments:

  • Auto Curve Detection maximum gap (pixels) (3 by default) is how far the detection may jump over a break in the curve. Pieces further apart are treated as separate curves.
  • Auto Curve Detection maximum turn (degrees) (45 by default) is how much the direction may change from one step to the next, which stops the chain from following a grid line, text or an axis that touches the curve.
  • Auto Curve Detection function assumption cuts the walk where x starts to go backwards, for graphs where every x has exactly one y. Turn it off for relation curves that legitimately loop back.
  • Auto Curve Detection point placement decides whether a created point stays on the traced path (the upstream behavior) or moves to the middle of the curve band - see below.
  • A single detection stops at 5000 points; click again further along a long curve.

Digitizing quality report

The Digitize > Quality Report... entry lists the digitized points that deserve a second look, so a curve does not have to be checked by eye point by point. The candidates are:

  • Points whose x value repeats the previous point, or goes backwards. These are candidates rather than errors, since a curve that is digitized as a relation may legitimately revisit the same x.
  • Points where the slope changes abruptly compared to the typical change of the curve, which catches a wrong point on an otherwise smooth curve.
  • Points that sit on top of a point of another curve, which usually means one curve was digitized twice.
  • Points outside the range covered by the axis points.

Double click a row to jump to that point in the document. The report can be saved as a comma separated file, which is useful after changing the color filter or the grid removal settings, or before exporting the data.

Point origin, and deleting automated points

Two options in Settings > General work together:

  • Show which points were placed automatically draws points that were created by the Segment Fill, Point Match or Auto Curve Detection tools with a dashed outline, so they can be told apart from the points placed by hand. The curve colors are not changed. The dashed points are exactly the ones that were derived from the filter settings, which makes them the ones to review after the filter changed.
  • Enable commands that work on automatically placed points adds Edit > Delete Automated Points, which removes every automated point while keeping the points placed by hand, in a single undoable step. Digitize the affected curves again afterwards. This is the quick way to re-digitize after the color filter or the grid removal settings changed.

Band centering of filled points

Auto Curve Detection point placement in Settings > Segments moves created points to the middle of the curve band instead of leaving them on the traced path, which is more accurate on a thick or anti-aliased line:

  • Traced path (upstream behavior) is the default and matches the original application.
  • Center of the curve pixels moves the point to the middle of the curve pixels in its column.
  • Darkness weighted center of the curve pixels also moves the point to the middle, but weights the pixels by darkness, which follows the dark middle of a band with soft edges.

Axis point review

With the option in Settings > General, defining a coordinate system from axis points that look wrong is questioned first: axis points with duplicate coordinates, or with x or y values that go backwards, are reported and can be corrected before the transformation is built from them.

Auto-save and crash recovery

The option Auto-save a recovery file while the document is modified in Settings > General writes a recovery copy of the document at a chosen interval while there are unsaved changes. If Engauge exits unexpectedly, the next start offers to recover the copy, so the digitizing work is not lost. The recovery file is a normal Engauge document that contains the image, so recovering does not depend on the original image file. The copy is removed as soon as the document is saved or closed normally.

Batch processing from the command line

A folder of images can be digitized from one template document without opening the user interface:

  Engauge -batchtemplate <template.dig> [-batchout <dir>] [-batchcontinue] <images...>

The template supplies the axis points, the color filter, the grid removal and the export format. -batchout chooses the output directory and -batchcontinue keeps going after a failed image instead of stopping. This is the tool for a measurement series that has to be re-digitized after a filter change.

New from template

File > New From Template... starts a new document from a saved template, so a new image is digitized with the same axis points, filters and export format as the template. The most recently used templates are offered in the same menu.

Export format presets

Settings > Export Format can save the complete export configuration - format, separators, precision, curve and coordinate system selection - under a name, and restore it later. Useful when several projects use different export layouts.

Point Match options and keys

Two settings in Settings > Point Match control the search:

  • Correlation threshold accepts candidates whose score is above the threshold. Raise it for fewer but safer matches, lower it for hard images.
  • Search radius multiplier limits how far from the click a candidate may be found. A value of zero keeps the upstream behavior of searching the whole image.

While a candidate point is being decided, Down skips it without adding a point, and Escape skips all remaining candidates in this round.

Arrow key acceleration

A selected point still moves one screen pixel per arrow key press, which is the upstream behavior. Shift with an arrow key moves ten pixels, and Control with an arrow key moves fifty pixels, which makes crossing a large image practical.

Themes, high DPI, zoom and diagnostics

  • Settings > General offers the themes System, Light and Dark. User curve colors are never changed.
  • Icons stay crisp at 150% and 200% display scaling; the high DPI behavior needs no setting.
  • Compact zoom controls replaces the twenty entry zoom menu with a combo box plus a fill entry.
  • Digitize > Quality Report... jumps to a listed point by double click (see above).
  • Help > About shows the version, the Qt runtime and the build date. Help > Copy Diagnostics puts the same information, plus the settings and the loaded document details, on the clipboard or into a file. Nothing is sent anywhere - the text is for a bug report or for the IT department of a closed network.

Closed network deployments

This fork is built for use on machines without internet access:

  • The installer and the portable package contain every runtime file, including the redistributable, the help file and the translations, so nothing is downloaded at run time.
  • The network code is compiled out of the Windows build, so the application only ever touches local files.
  • The quality report, the recovery files and the settings are all local file access. Nothing is sent anywhere.
  • Updating is a manual procedure, described in the OFFLINE_UPDATE.md file next to the program.

Other fixes

  • The Guidelines tool uses Shift+F9, which no longer collides with the Scale Bar tool.
  • The Segment Fill settings are reachable again through the Settings > Segment Fill... entry.
  • The Help > Language menu switches the user interface language, including Korean.
